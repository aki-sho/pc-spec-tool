PC Spec Tool Portable 1.0.2
================================

【起動方法】
ZIPを展開し、PC-Spec-Tool-Portable-1.0.2.exe をダブルクリックしてください。
DLL、resources、localesなどの追加ファイルは不要です。

【PortableDataの場所】
初回起動時に、EXEと同じ場所へ次のフォルダーが自動作成されます。

PC-Spec-Tool-PortableData

ElectronのuserData、sessionData、設定、ログ、キャッシュ、一時ファイルは、
このPortableDataフォルダー内へ保存されます。

【別の場所へ移動する方法】
1. PC Spec Toolを終了します。
2. 設定やデータも引き継ぐ場合は、EXEとPC-Spec-Tool-PortableDataを一緒に移動します。
3. EXEだけを移動した場合は、次回起動時に移動先のEXEの隣へ新しいPortableDataが作成されます。

【削除方法】
PC Spec Toolを終了してから、次の2つを削除してください。

- PC-Spec-Tool-Portable-1.0.2.exe
- PC-Spec-Tool-PortableData

レジストリへのインストール情報やアンインストール操作はありません。
